# EARCRAFT — Super Admin & CMS Operational Manual

Welcome to the Earcraft SaaS Admin Dashboard. This manual explains how to control storefront branding, products, orders, media, and marketing without changing code.

## 1. Accessing the Admin Hub
- Navigate to `/admin` on your storefront deployment.
- Use the mode switcher in the top navigation bar to toggle between Storefront view and Admin Mode.

## 2. Super Admin CMS Control
- Go to **Super Admin CMS** (`/admin/cms`).
- **Brand Identity**: Edit the global site title and tagline in real-time.
- **Announcement Ticker**: Modify promo text, link, background color, and font color.
- **Hero Carousel Banners**: Update primary hero headings, subtitles, background images, and CTAs.

## 3. Product & Inventory CRUD
- Go to **Product Catalog** (`/admin/products`).
- Click **Add Product SKU** to launch the creation modal.
- Input SKU, HSN Code, 3% GST percentage, Barcode, price, stock level, and high-res image URL.
- Use **Export CSV** to download inventory snapshots.

## 4. Order Fulfilment
- Go to **Order Fulfilment** (`/admin/orders`).
- Update pipeline status: `PENDING` -> `PROCESSING` -> `PACKED` -> `SHIPPED` -> `DELIVERED`.
- Click **PDF Invoice** or **Packing Slip** to generate printables.
